## 什么是 Storyweave？

Storyweave 是一个 AI 驱动的故事大纲生成器，帮助作家、游戏设计师和内容创作者通过互动式问答构建结构化的故事框架。

不再面对空白页面，Storyweave 通过一系列深思熟虑的问题引导你提取故事的核心要素——主题、人物、冲突、世界——然后将一切映射到经过验证的叙事结构上。

## 核心功能

### 🎯 引导式问答框架
- 渐进式信息收集（一次 1-2 个问题）
- 不会信息过载——逐步构建大纲
- 捕捉灵感碎片（inspirational sparks）

### 📚 10 种经典故事模板

| 模板 | 最适合 |
|------|--------|
| 三幕式结构 | 通用故事讲述 |
| 英雄之旅 | 冒险、奇幻、成长 |
| 拯救猫咪！15个节拍 | 电影剧本、商业小说 |
| 谢弗三角场景结构 | 场景层面细化 |
| 极简五点 | 短篇故事、概念验证 |
| 七点结构 | 系列故事 |
| 非线性叙事 | 时间循环、倒叙 |
| 三幕五段式 | 传统戏剧、中国戏曲 |
| 冲突升级 | 悬疑、惊悚 |
| Kishotenketsu | 文艺、实验性（东亚叙事） |

### 👤 5 种人物弧线类型
- 正直弧线（成长）
- 堕落弧线（崩塌）
- 平线弧线（信念改变世界）
- 堕落正直（跌倒与重生）
- 圆形弧线

## 使用方法

### 对话示例

> "我想写一部科幻小说，讲述一位语言学家发现外星人通过音乐交流。"

> "帮我写一个发生在沿海小镇的谋杀悬疑故事大纲。"

> "我在开发一个游戏叙事，关于一个孩子寻找失去的记忆。"

### 工作流程

1. **问答阶段**：Storyweave 询问故事的类型、主题、人物和冲突
2. **模板选择**：根据故事类型推荐最合适的叙事结构
3. **大纲生成**：完整大纲生成，所有故事节拍已映射
4. **迭代深化**：按需深入特定场景、人物或弧线

## 模板深度解析

### 三幕式结构
```
第一幕 (25%) → 建置、催化剂、第一转折
第二幕 (50%) → 趣味与游戏、中点、危机
第三幕 (25%) → 高潮、解决
```

### 英雄之旅（12 阶段）
```
平凡世界 → 召唤 → 拒绝 → 导师 → 门槛
→ 试炼 → 洞穴 → 考验 → 奖赏 → 返回 → 复活 → 回归
```

### 拯救猫咪！（15 个节拍）
```
开篇画面 → 主题 → 设置 → 催化剂 → 辩论
→ 进入第二幕 → B故事 → 趣味游戏 → 中点
→ 反派逼近 → 一切皆失 → 黑暗夜晚 → 进入第三幕
→ 高潮 → 最终画面
```

## 哲学

- **灵活性优于刚性**：模板是工具，不是束缚
- **完成优于完美**：粗糙但完整的大纲胜于完美的概念
- **捕捉一切**：午夜灵感碎片？那是宝藏
- **渐进深化**：先搭骨架，后续细化
