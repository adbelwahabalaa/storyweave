# 经典故事结构模板大全

本文档收录最常用的故事大纲模板，供 Story Outline Skill 调用。

---

## 1. 三幕式结构（Three-Act Structure）

最经典、最通用的叙事框架，将故事分为三个部分。

### 比例
- **第一幕（建置）**：25%
- **第二幕（对抗）**：50%
- **第三幕（解决）**：25%

### 核心节拍

#### Act 1 - 建置（Setup）
| 节拍 | 说明 |
|------|------|
| **开篇画面** | 展示故事世界和主角的日常/现状 |
| **主题暗示** | 用某种方式暗示故事的核心主题 |
| **设定/背景** | 建立故事发生的世界、规则、时间地点 |
| **催化剂（Catalyst）** | 打破现状的事件，故事正式开始 |
| **讨论/抗拒** | 主角对变化的第一反应和挣扎 |
| **第一幕转折点** | 主角做出决定，接受挑战，进入第二幕 |

#### Act 2 - 对抗（Confrontation）
| 节拍 | 说明 |
|------|------|
| **B故事（副线）** | 通常是爱情线或友情线，承载主题 |
| **玩味与游戏（Fun and Games）** | 故事最有趣的部分，展示主角的能力 |
| **中点（Midpoint）** | 重大转折：伪胜利或伪失败，主角地位改变 |
| **坏人们逼近** | 反派加大压力，代价上升 |
| **一切皆失** | 主角遭遇重大失败，几乎失去所有 |
| **灵魂黑夜（Dark Night of the Soul）** | 最低谷，准备放弃或重新思考 |
| **第二幕转折点** | 主角获得洞察，找到解决方法 |

#### Act 3 - 解决（Resolution）
| 节拍 | 说明 |
|------|------|
| **最终对决** | 高潮冲突 |
| **结局画面** | 展示新世界/新常态 |
| **主题答案** | 主题在结局中得到回应 |

## 2. 英雄之旅（Hero's Journey / Monomyth）

约瑟夫·坎贝尔的「单一神话」理论，克里斯托弗·沃格勒在《作家之旅》中将其系统化。

### 12个阶段

#### 平凡世界（Ordinary World）
主角在故事开始时的日常生活和常态。

#### 冒险召唤（Call to Adventure）
主角收到挑战、任务或使命。

#### 拒绝召唤（Refusal of the Call）
主角犹豫或拒绝，通常因为恐惧。

#### 遇见导师（Meeting the Mentor）
主角遇到导师，获得建议、训练或工具。

#### 跨越第一道门槛（Crossing the First Threshold）
主角正式踏入冒险世界，无法回头。

#### 试炼、盟友与敌人（Tests, Allies, Enemies）
主角遭遇挑战，认识新朋友和新敌人，适应新世界规则。

#### 接近最深处的洞穴（Approaching the Inmost Cave）
主角接近核心目标或最大挑战的地点。

#### 严峻考验（The Ordeal）
主角面对最大的挑战或死亡体验。

#### 获得奖赏（Reward）
主角成功通过考验，获得某种奖赏。

#### 回去的路（The Road Back）
主角开始返回，但反派追击。

#### 复活（Resurrection）
最终考验，主角必须在死亡边缘经历蜕变。

#### 满载而归（Return with the Elixir）
主角带着改变/成长/奖赏回归平凡世界。

### 英雄之旅变体：17个节拍（Christopher Vogler）

| # | 节拍 | 说明 |
|---|------|------|
| 1 | 平凡世界 | 主角的日常 |
| 2 | 冒险召唤 | 打破现状的事件 |
| 3 | 拒绝召唤 | 恐惧或疑虑 |
| 4 | 遇见导师 | 获取能力或指引 |
| 5 | 跨越门槛 | 进入冒险世界 |
| 6 | 试炼、盟友与敌人 | 新世界的规则 |
| 7 | 接近最深洞穴 | 接近核心目标 |
| 8 |严峻考验 | 最大挑战 |
| 9 | 获得奖赏 | 胜利成果 |
| 10 | 返回之路 | 回归的旅程 |
| 11 | 复活 | 最终蜕变 |
| 12 | 满载而归 | 新生 |

## 3. 拯救猫咪（Save the Cat!）— 15个节拍

布莱克·斯奈德的电影剧本结构体系。

| # | 节拍 | 说明 | 位置 |
|---|------|------|------|
| 1 | 开篇画面 | 展示故事调性和主角现状 | 第1页 |
| 2 | 主题陈述 | 角色提出主题相关问题 | 第1-5页 |
| 3 | 设定钩子 | 吸引观众注意力的场景 | 第1-10页 |
| 4 | 催化剂 | 打破现状的事件 | 第10-12页 |
| 5 | 讨论/抗拒 | 主角对变化的第一反应 | 第12-25页 |
| 6 | 第二幕开始 | 主角进入新世界 | 第25页 |
| 7 | B故事 | 副线故事，通常是爱情/主题线 | 第30页左右 |
| 8 | 玩味与游戏 | 故事最有趣的片段 | 第30-55页 |
| 9 | 中点 | 伪胜利或伪失败 | 第55页 |
| 10 | 坏人们逼近 | 反派加大威胁 | 第55-75页 |
| 11 | 一切皆失 | 重大失败 | 第75页 |
| 12 | 黑暗时刻 | 最低谷 | 第75-85页 |
| 13 | 第三幕转折点 | 找到解决方案 | 第85页 |
| 14 | 最终对决 | 高潮 | 第85-110页 |
| 15 | 结局画面 | 主题的最终呈现 | 最后一页 |

### 故事物种（Story Species）

Save the Cat! 体系还定义了6种「故事物种」：

1. **Monster in the House**（屋内怪物）：恐惧驱动，经典恐怖/惊悚
2. **Golden Fleece**（金羊毛）：旅程驱动，一群人为目标奋斗
3. **Out of the Box**（突破框框）：创意/发明驱动
4. **Rite of Passage**（成年礼）：成长驱动，主角面对成长挑战
5. **Buddy Love**（伙伴之爱）：关系驱动，两个角色相互改变
6. **Whydunit**（推理悬疑）：真相驱动，调查/解谜为主

## 4. 谢弗三角（Scene Structure - Dan O'Neill）

每个场景的内部结构：

| 阶段 | 问句 | 说明 |
|------|------|------|
| 冲击 | 发生了什么？ | 打破现状的事件 |
| 反应 | 角色如何感受？ | 角色的情感反应 |
| 解决 | 角色做了什么？ | 角色决定/行动 |

### 谢弗三角的特点
- 场景必须有变化，无变化的场景应该删除
- 角色反应必须具体且可见
- 每个场景应推动故事向前发展

## 5. 极简五点结构

适合短篇或概念验证的最简化大纲。

| # | 节拍 | 说明 |
|---|------|------|
| 1 | **起点** | 主角的日常/现状 |
| 2 | **触发事件** | 打破现状的事件 |
| 3 | **对抗** | 主角面对冲突和障碍 |
| 4 | **高潮** | 最终对决/最大挑战 |
| 5 | **结局** | 故事如何收尾 |

## 6. 七点故事结构（The Seven-Point Story Structure）

| # | 节拍 | 说明 |
|---|------|------|
| 1 | **钩子（Hook）** | 开篇，吸引读者的起点 |
| 2 | **第一转折点** | 故事方向的第一次重大改变 |
| 3 | **捏合（Pinches）** | 制造压力的时刻（多个） |
| 4 | **中点** | 重大揭示或立场反转 |
| 5 | **第二转折点** | 故事方向的第二次重大改变 |
| 6 | **结局** | 最终解决方案 |
| 7 | **悬念/钩子（Final Hook）** | 收尾，如需续集则留钩子 |

### 关键原则
- 开头和结尾必须连接
- 第一转折点和第二转折点必须对应（一个开启，一个收束）
- 中点是主角立场的反转点

## 7. 非线性叙事结构

### A. 时间循环（Groundhog Day Loop）
1. 陷入循环
2. 初始反应（享乐/混乱）
3. 寻求逃脱
4. 多次尝试失败
5. 绝望与意义探寻
6. 顿悟与转变
7. 打破循环，结局

### B. 倒叙结构（Memento / Rashomon）
从结局或结局附近开始，逐步揭示导致现状的事件。

### C. 多视角叙事
不同章节从不同角色的视角讲述同一事件。

## 8. 三幕五段式（经典戏剧结构）

中国传统戏曲和西方古典戏剧的经典结构。

| 段落 | 说明 |
|------|------|
| **起** | 故事开端，介绍人物和背景 |
| **承** | 事件发展，逐步建立冲突 |
| **转** | 高潮转折，冲突爆发 |
| **合** | 冲突解决，故事收尾 |

---

## 9. 冲突升级结构（Escalating Stakes）

适合商业/悬疑/惊悚类型的结构。

| 层级 | 说明 | 示例 |
|------|------|------|
| L1 个人 | 影响主角个人 | 失业、疾病 |
| L2 关系 | 影响主角在乎的人 | 家人/朋友受威胁 |
| L3 社区 | 影响更大群体 | 城市/国家 |
| L4 世界 | 影响整个世界 | 文明存亡 |
| L5 宇宙 | 影响整个宇宙 | 维度/时间线 |

---

## 10. Kishotenketsu（四幕结构）

东亚叙事传统（中日韩）常用的结构，无需强烈冲突。

| 幕 | 说明 |
|---|------|
| **起** | 介绍人物和背景 |
| **承** | 发展第一部分建立的情节 |
| **转** | 突然引入意想不到的转折 |
| **合** | 结尾，将前面所有元素联系起来，产生意义 |

## 模板选择指南

| 故事类型 | 推荐模板 |
|----------|----------|
| 商业电影/小说 | Save the Cat! / 三幕式 |
| 冒险/奇幻/成长故事 | 英雄之旅 |
| 短篇故事 | 极简五点 / 谢弗三角 |
| 悬疑/推理 | 冲突升级 / 七点结构 |
| 文艺/实验性 | Kishotenketsu / 非线性 |
| 系列故事 | 七点结构（带悬念钩子） |
| 剧本 | Save the Cat! |
| 电视剧集 | 分集三幕式（每集独立+主线贯穿） |

## 人物弧线类型

每个故事结构都可以配合以下人物弧线：

| 弧线类型 | 说明 | 示例 |
|----------|------|------|
| **正直弧线（Positive Arc）** | 从缺陷到成长 | 自私→牺牲 |
| **堕落弧线（Negative Arc）** | 从正常到崩溃 | 善良→邪恶 |
| **平线弧线（Flat Arc）** | 坚持信念改变他人 | 唐吉诃德 |
| **堕落正直（Fall and Rise）** | 起伏后重生 | 失败→放弃→重整 |
| **圆形弧线（Circular）** | 回到起点但有变化 | 成长后选择回归 |

### 弧线节点（针对主角）

1. **缺陷（Flaw/Wound）**：角色内心深处的恐惧或创伤
2. **欲望（Want）**：角色外在追求的目标
3. **需求（Need）**：角色真正需要的东西（通常是被爱的感觉）
4. **伪装（Lie）**：角色相信的谎言/错误信念
5. **真相（Truth）**：角色最终认识到的事实
6. **行动（Action）**：基于真相做出的改变
